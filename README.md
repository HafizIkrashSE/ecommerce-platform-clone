# 📦 E-Commerce Platform Clone
This is an e-commerce marketplace homepage clone that I built using HTML and CSS while learning front-end web development. The project helped me practice layouts, Flexbox, styling, and creating a real-world website interface.

## 📖 About
I created this project to improve my HTML and CSS skills by recreating the layout of a modern e-commerce homepage. Through this project, I learned how to structure large web pages, work with Flexbox, organize content sections, and design responsive layouts without relying on branded assets.

## ✨ Features
* Modern e-commerce navigation bar
* Search bar with integrated magnifying glass icon
* Address selection, user account, orders, and cart sections
* Navigation panel with category menu links
* Large hero banner showcase section
* Product category showcase grids and cards
* Interactive UI elements with custom hover transitions
* Multi-section organized footer with language and currency settings
* Fully structured layout using clean CSS Flexbox

## 🛠️ Technologies Used
* **HTML5** (Semantic structuring)
* **CSS3** (Custom layouts, variables, and transitions)
* **Flexbox** (Responsive component alignment)
* **Font Awesome Icons v6.5.1** (Scalable vector icons)
